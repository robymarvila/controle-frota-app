# Diretrizes e Regras do Projeto (fleet-operacao-app)

## REGRA CRÍTICA: ENVIO PARA O GITHUB (GIT PUSH)

- **JAMAIS** faça `git push` ou envie código/versões novas para o repositório remoto do GitHub sem a autorização **EXPLÍCITA e DIRETA** do usuário.
- Todas as alterações, correções e builds devem ser feitas **EXCLUSIVAMENTE NO CÓDIGO LOCAL** (`src/`, build local, capacitor sync).
- Quando tudo estiver testado e verificado no código local, informe o usuário e aguarde a confirmação formal ("Pode subir para o GitHub", "Autorizado", etc.) antes de rodar qualquer comando de `git push`.
